1. Décompressez le ZIP.
2. Dans votre dépôt GitHub, remplacez les anciens fichiers par ceux-ci.
3. Vérifiez que `index.html`, `styles.css`, `script.js` et le dossier `images` sont à la racine.
4. GitHub Pages se mettra à jour automatiquement après quelques minutes.
