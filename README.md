# VANILLE ROYALE — Version GitHub iPhone sans dossier assets

Tous les fichiers et toutes les images se trouvent directement à la racine.

## Mise en ligne depuis un iPhone

1. Décompressez le fichier ZIP dans l’application Fichiers.
2. Ouvrez votre dépôt GitHub.
3. Appuyez sur **Add file**, puis **Upload files**.
4. Sélectionnez tous les fichiers extraits :
   - index.html
   - styles.css
   - script.js
   - README.md
   - toutes les images PNG
5. Vérifiez qu’ils apparaissent tous directement à la racine du dépôt.
6. Appuyez sur **Commit changes**.

Il ne faut créer aucun dossier `assets`.
